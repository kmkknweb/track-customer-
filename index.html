ติดตั้งไว้บนหน้าจอมือถือ

Android (Google Chrome)

  1. เปิดหน้า PWA นี้ด้วย Chrome
  2. กดเมนู ⋮ ด้านบน
  3. เลือก ติดตั้งแอป หรือ เพิ่มไปยังหน้าจอหลัก
  4. กดยืนยัน จากนั้นกดไอคอน “ระบบงานกรรมการ” ได้เลย

iPhone (Safari)

  1. เปิดหน้า PWA นี้ด้วย Safari
  2. กดปุ่ม แชร์
  3. เลือก เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)
  4. กด เพิ่ม

ถ้าเปิดจาก LINE แล้วไม่พบเมนูติดตั้ง ให้เลือกเปิดลิงก์ใน Chrome หรือ Safari ก่อน การติดตั้ง PWA ทำได้เมื่อหน้าเว็บถูกเผยแพร่ผ่าน HTTPS แล้ว ไม่ใช่ไฟล์ HTML ที่เปิดจากเครื่องโดยตรง
