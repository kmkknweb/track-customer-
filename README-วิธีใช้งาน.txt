PWA ระบบงานกรรมการ — วิธีนำไปใช้งาน
==================================

แอปนี้เป็น "ทางเข้ารวม" เท่านั้น ไม่สร้างฐานข้อมูลลูกค้า ไม่บันทึกข้อมูลลูกค้า
และไม่เปลี่ยนระบบ Google Apps Script ที่ใช้อยู่

ระบบที่เชื่อมต่อไว้แล้ว
1) แอปติดตามผู้ประมูล (งานประมูล 2569)
   https://script.google.com/macros/s/AKfycbzc0U-0vaOZS_mSXzOhi9OM5jQqF_RuKgz6b8OFBTygHxgf-DJ92sGF7Qjegucu4DJixA/exec
2) แอปติดตามผู้ติดตั้งโคมไฟและบัตรงานง่วนเซียว (2570)
   https://script.google.com/macros/s/AKfycbyJ8RyuOds3BDgM2bsHH2-D5KHZ8u2DDbvGaae2zW1ORdKyOVvkWCR6_fLmkEDy9tG8/exec

วิธีทดสอบก่อนนำขึ้นเว็บไซต์
- เปิด index.html ด้วย Chrome บนคอมพิวเตอร์ จะเห็นหน้าเมนูและกดลิงก์ได้
- แต่การ "ติดตั้ง PWA" ต้องขึ้นเว็บ HTTPS หรือทดสอบบน localhost

วิธีเผยแพร่ (ทางเลือกที่ง่าย)
- เข้า https://app.netlify.com/drop ในเบราว์เซอร์ และเข้าสู่ระบบ
- นำ "โฟลเดอร์ committee-hub-pwa" ที่แตก ZIP แล้ววางเพื่อเผยแพร่
- บริการจะให้ที่อยู่เว็บไซต์แบบ HTTPS (เช่น https://ชื่อเว็บ.netlify.app)
- เปิดที่อยู่นั้นบนมือถือ แล้วติดตั้งไอคอนด้วยเมนูเบราว์เซอร์
- หากหน้าจอผู้ให้บริการเปลี่ยนแปลง ให้เลือกการ Deploy เว็บไซต์จากโฟลเดอร์

Android / Google Chrome
1. เปิดลิงก์ HTTPS ที่เผยแพร่แล้วด้วย Chrome
2. กดเมนู ⋮ > ติดตั้งแอป หรือ เพิ่มไปยังหน้าจอหลัก
3. กดติดตั้ง/เพิ่ม จะได้ไอคอน "งานกรรมการ" บนมือถือ

iPhone / Safari
1. เปิดลิงก์ HTTPS ที่เผยแพร่แล้วด้วย Safari
2. กดแชร์ > เพิ่มไปยังหน้าจอโฮม > เพิ่ม

ข้อควรรู้
- กดจากเมนูแล้วจะเปิด Google Apps Script เดิมในหน้าต่างเบราว์เซอร์
  (ไม่ฝังเว็บไว้ในหน้าเมนู PWA) เพื่อให้เข้ากันได้กับการเข้าสู่ระบบ Google
- หน้าเมนูอาจเปิดได้เมื่อออฟไลน์ แต่ 2 ระบบปลายทางต้องใช้อินเทอร์เน็ต
- PWA นี้ไม่ทำให้ระบบปลายทางที่อนุญาตทุกคนเข้าใช้งานกลายเป็นระบบส่วนตัว
  ต้องตั้งค่าการเข้าถึงแต่ละ Google Apps Script ตามสิทธิ์ที่เหมาะสมด้วย
- หากภายหลังเปลี่ยนลิงก์ Google Apps Script ต้องแก้ href ใน index.html
  แล้วนำเว็บไซต์เวอร์ชันใหม่ขึ้นเผยแพร่ (ถ้าต้องอัปเดตแคชให้เปลี่ยนเวอร์ชันใน sw.js)
- QR Code ของ "PWA ตัวกลาง" ต้องสร้างหลังได้ลิงก์เว็บไซต์ HTTPS แล้ว

ไฟล์
- index.html : หน้าเมนูรวม 2 ระบบ
- manifest.webmanifest : ค่าการติดตั้ง PWA
- sw.js : แคชเฉพาะหน้าเมนู ไม่แคชข้อมูลลูกค้า
- icons/ : ไอคอนมือถือ
